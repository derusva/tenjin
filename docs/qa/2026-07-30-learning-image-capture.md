# Tenjin 学习画像与单图捕获验收记录

日期：2026-07-30

范围：学习画像文档分层、应用内单张图片记录、可选查词答案、图片复习与本机持久化。

## 交付边界

本轮交付：

- GPT 学习总结拆为本机私有画像、公开解释策略、待验证产品假设。
- 首页直接从 Photos / 文件选择器选一张图片，不依赖 Shortcut。
- 接受内容确认为 JPEG、PNG、HEIC 或 HEIF，且当前浏览器能够实际预览的图片；单张上限 20 MB。
- 图片可单独保存，也可与文字或“查到的意思 / 解释”一起保存。
- 只有存在非空答案的图片查词记录才生成 R 通道复习材料；无答案纯图只进入 capture 与最近记录。
- 图片 Blob、文件名、媒体类型、字节数和 SHA-256 只保存在本机 context；核心事件只引用 context hash。
- 图片摘要写入前后都会按真实 Blob 内容复核；撤销仅在最后一个有效引用消失后清理图片。

本轮明确不交付：

- 多图、OCR、语音转写、GPT 解析。
- Shortcut 安装或手工动作搭建。
- 跨设备图片同步、云端保存、图片完整导出与恢复。
- 浏览器无法解码的 HEIC / HEIF 自动转码。

## 真实浏览器验证

使用构建后的 PWA 和真实 Chrome 浏览器完成以下闭环：

1. 首页加载完成，移动端与桌面端布局可用。
2. 通过真实文件选择控件选择仓库内 1.8 MB PNG。
3. 等待内容签名、SHA-256 与浏览器解码完成，看到图片预览。
4. 填写查词答案并保存，最近记录显示本机图片。
5. 打开复习；揭晓前答案不可见，揭晓后答案可见。
6. 关闭并重新启动同一浏览器工作副本，最近记录与图片仍从 IndexedDB 恢复。
7. 重启后再次进入复习，题面图片可见且答案仍保持隐藏直到揭晓。

这证明了当前 Chrome 环境中的选图、校验、预览、保存、IndexedDB 重载、复习和揭晓链路；不能替代真实 iPhone Safari 主屏 Web App 或 HEIC / HEIF 解码验收。

## 真实 iPhone 验收清单

以下步骤是发布后的最终设备验收，不应由桌面结果代替：

1. 用 Safari 打开线上 Tenjin，添加到主屏幕后只从主屏图标进入。
2. 首次完整加载后切换飞行模式，确认首页仍能打开。
3. 从应用内选择一张 P5R 截图 A，不填答案并保存；最近记录应显示图片。
4. 再选一张截图 B，填写“查到的意思 / 解释”并保存；最近记录应显示图片和答案摘要。
5. 强制关闭并重新打开主屏 Tenjin，保持离线；A、B 的图片预览都应仍然存在。
6. 进入复习：A 不应进入队列；B 应以图片为题面，揭晓前隐藏答案，揭晓后显示答案。
7. 保存截图 C 后在 8 秒内撤销；强制关闭并重新打开后，C 不应出现在最近记录或复习中。
8. 另选一张真实 HEIC / HEIF：若当前 WebKit 可以解码，应成功预览和保存；否则应在保存前明确拒绝，不能生成空白记录。

## 验收风险说明

- 数据只存在当前主屏 Web App 的 IndexedDB；删除应用、系统清理存储或更换浏览器工作副本都可能丢失。
- 当前导出不构成图片完整备份。正式长期积累图片前，仍需后续交付可验证的图片导出与恢复。
- 20 MB 是单张硬上限，不代表已经验证大量图片长期积累时的配额、性能或迁移能力。
- 因此本轮可以验收为“无需 Shortcut 的单图 MVP”，不能验收为“媒体资料库”或“跨设备采集系统”。
